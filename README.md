Gồm 3 system chính:
- Input system(Chưa xong)
    - OCR / Receipt scan.
    - Voice Typing.
    - Manual Typing.
- Storage system(Chưa xong)
    - storage (Green, Yellow, Red)
    - Cycle system (hệ thống tự chuyển đổi vùng dựa vào hạn sử dụng).
- Recommendation system(chưa xong)
    - Tạo/tìm database công thức.
    - Thuật toán lấy nguyên liệu từ vùng RED (và các vùng khác) để gợi ý món ăn.
